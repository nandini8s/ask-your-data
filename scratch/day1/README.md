# Day 1 experiments

These scripts are preserved as project history, not part of the current app or
test workflow. `day1.py` and `day1_tools.py` contain early direct Gemini
experiments. `check_key.py` prints the first four characters of the configured
API key, so do not run it in a shared terminal or capture its output.

The supported application entry points are `streamlit_app.py`, `loop.py`, and
`run_evals.py`.
