# Ask Your Data

An AI agent that answers plain-English questions about a SQLite database by
calling tools (get_schema, run_sql) in a loop.

**Status:** work in progress (database tools, agent loop, and evaluation runner).

## Data
`campus.db` is synthetic smart-campus electricity data with planted patterns,
generated by `make_db.py`.

## Run it
1. `pip install -r requirements.txt`
2. Copy `.env.example` to `.env` and add your Gemini API key
3. `python3 make_db.py`
4. `python3 loop.py`

## Streamlit UI

Install the project dependencies with `pip install -r requirements.txt`;
Streamlit is included. Before launching the UI, make sure `campus.db` exists.
If it is missing, generate the local database with `python3 make_db.py`, and
configure the Gemini API key in the local `.env` file.

Launch the UI with:

```sh
streamlit run streamlit_app.py
```

The “View executed SQL” expander displays the actual query strings captured
from `run_sql` tool calls made by the existing agent. It does not construct or
execute SQL separately.

## Evaluations

Run selected questions with `python3 run_evals.py --ids 1 2`, or choose a split
with `--split dev` or `--split test`. `--sleep SECONDS` adds a pause between
questions. The runner appends one JSON record per question to
`evals/results_<model>.jsonl`; these generated logs stay local and are ignored by
Git. The question definitions and scoring rules in `evals/questions.json` and
`evals/scoring.py` are the reproducible evaluation inputs.

## Request handling and safety

Model requests use a 60-second timeout with SDK retries disabled. The agent
retries an actual request timeout once and retries HTTP 503 responses up to
three times with a two-second wait. HTTP 429 responses are not retried and are
returned as `error: "rate_limited"`. Other API errors return an empty answer
and their error text. The evaluator records API failures with
`status: "api_error"` and `score: null`, and excludes them from accuracy.

The database connection is opened read-only. `run_sql` accepts a single
`SELECT` statement and rejects other SQL; `get_schema` only reads table and
column metadata and sample rows. The evaluator also checks that the readings
table still contains 11,520 rows after questions 21 and 30.
